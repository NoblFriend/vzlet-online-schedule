# Расписание

Статический сайт: `index.html` читает `schedule.js` и показывает расписание по потокам и классам:
календарь недели (по умолчанию) и таймлайн всех занятий. Клик по неделе в таймлайне открывает её календарь.
Данные лежат в `schedule.js` как обычный JSON внутри `var SCHEDULE = {...};` — так страница
открывается и двойным кликом с диска, и на GitHub Pages. Отдельный `.json` браузер
по протоколу `file://` подгружать запрещает.

## Публикация на GitHub Pages

1. Создать репозиторий `schedule`, публичный.
2. Положить в корень `index.html`, `schedule.js`, `README.md`.
3. Settings → Pages → Source: Deploy from a branch.
4. Branch: `main`, папка `/ (root)` → Save.
5. Через минуту сайт: `https://<логин>.github.io/schedule/`

## Правка расписания

1. Открыть `schedule.js` на GitHub.
2. Нажать ка## Формат `schedule.js`

```
title      заголовок страницы
subtitle   подпись под заголовком
duration   длительность занятия в минутах по умолчанию, необязательно (иначе 90)
streams    потоки: вкладки «Всерос», «Рег»
overrides  точечные изменения отдельных занятий
```

Поток:

```
id       уникальная строка
name     название вкладки
short    метка на занятиях при выборе «все», необязательно (иначе первая буква name)
skips    недели без занятий у этого потока: любая дата недели, "ГГГГ-ММ-ДД".
         Все курсы потока сдвигаются на неделю, нумерация занятий сохраняется.
series   курсы потока
```

Курс:

```
id        уникальная строка по всему файлу, на неё ссылаются overrides
group     вкладка класса: "7-9", "10-11"
name      название
teacher   преподаватель, необязательно
start     дата первого занятия. День недели берётся отсюда
time      "17:30". Без time курс показывается как «без времени» в своей неделе
duration  длительность в минутах, необязательно
count     число занятий
color     1 синий, 2 зелёный, 3 красный, 4 фиолетовый, 5 оранжевый, 6 бирюзовый
```

Точечное изменение: меняет одно занятие, остальные не сдвигаются.

```
series   id курса
idx      номер занятия внутри курса, с 1
date     новая дата, необязательно
time     новое время, необязательно
teacher  замена преподавателя, необязательно
cancel   true — занятие отменено
note     комментарий, показывается на занятии
```

```
{"series": "sferka-pro-1011", "idx": 3, "date": "2026-11-21", "time": "12:00", "note": "перенос"}
```
